# Pomodoro

A simple Pomodoro timer built with HTML, CSS, and JavaScript.

## Features
- 25-minute focus sessions with 5-minute short breaks and configurable long breaks.  
- Start, pause, and reset controls with visual progress indicators.  
- Clean, responsive UI built using vanilla web technologies.  

## Getting Started
1. Clone the repository:
   git clone https://github.com/vanshmehandru/pomodoro.git
2. Open index.html in your browser.
3. Customize durations in the script if needed.

## Project Structure
- index.html — App layout
- style.css — Styling
- script.js — Timer logic
